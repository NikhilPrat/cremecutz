# Creme Cutz Barbershop Website

Single-page, mobile-first site for Creme Cutz (UMass Amherst). Booking stays on Google Calendar.

## Stack
Plain HTML/CSS/JS generated by a small dependency-free Node script (`build.mjs`). Chosen for speed, zero build tooling to maintain, and fully static output. Content comes from `content/site-config.json`.

## Commands
- `npm run build`: generates `dist/`
- `npm start`: builds and previews at http://localhost:4173

## Deploy
Netlify / Vercel / Cloudflare Pages: build command `npm run build`, output directory `dist`. Set `siteUrl` in the config to the live domain.

## Layout
- `content/site-config.json`: all editable content
- `src/styles`, `src/scripts`: CSS and JS
- `public/`: images, favicon, share image
- `docs/HOW-TO-UPDATE.md`: guide for the owners
- `TODO.md`: open questions

## What improved vs. the old site
- Wix banner removed; dynamic copyright year
- Prices, services and the beard add-on on the page; Book button in header, hero, each card, and a mobile sticky bar (with call and text)
- Real gallery with lightbox (placeholders to swap), Instagram button ready once a handle is added
- Reviews, hours, FAQ, how-it-works and map sections with honest placeholders
- Local SEO: title, meta, Open Graph/Twitter, BarberShop JSON-LD, sitemap, robots
- Tracking parameters (`fbclid`, `utm_*`) stripped from outbound links
- Privacy and Accessibility pages rebuilt
- Accessible: skip link, keyboard menu and lightbox, focus states, 44px targets, reduced-motion support

## Not done
Lighthouse scores, Instagram in-app browser and device testing, and deployment were not run here. Dark mode, QR page and analytics (nice-to-haves) were skipped.
